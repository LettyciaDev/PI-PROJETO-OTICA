# PROJETO INTEGRADOR

# 👓 Vizzo Ótica — Site Institucional

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento do site institucional da **Vizzo Ótica**, com foco em presença digital, experiência do usuário e conversão de clientes.

O site está sendo desenvolvido por uma equipe, unindo design, front-end e back-end para criar uma solução completa, moderna e escalável.

---

## 🎯 Objetivos

* Apresentar a ótica e seus diferenciais
* Exibir produtos (óculos de grau e sol)
* Facilitar o contato com clientes
* Fortalecer a presença digital da marca
* Integrar com redes sociais

---

## 🧠 Contexto do Projeto

O projeto surgiu a partir da necessidade de digitalização do atendimento e organização da comunicação com clientes.

Além disso, faz parte do desenvolvimento prático em tecnologia, aplicando conceitos de front-end, back-end e design colaborativo.

---

## 🚀 Funcionalidades

* Página inicial com apresentação da marca
* Catálogo de produtos
* Seção de saúde visual
* Área de contato (WhatsApp)
* Estrutura preparada para futuras funcionalidades:

  * Reserva de óculos
  * Agendamento de exames

---

## 🛠️ Tecnologias Utilizadas

* React (Front-end)
* Django (Back-end)
* PostgreSQL (Banco de dados)
* Figma (Prototipação e design)
